# Website Stylekit for WordPress

The current plugin version is **2.6**. This repository is the source of truth for the WordPress plugin.

Website Stylekit imports and exports design variables and global classes for Elementor V4 and Bricks. See [the plugin readme](websitestylekit/readme.txt) for requirements, features, and the changelog.

## Install

1. Download [websitestylekit-2.6.zip](websitestylekit-2.6.zip).
2. In WordPress, open **Plugins → Add New → Upload Plugin**.
3. Upload the ZIP, install it, and activate **Website Stylekit**.

The editable plugin files are in [`websitestylekit/`](websitestylekit/). The ZIP contains those same files. Older ZIPs remain here for reference.
